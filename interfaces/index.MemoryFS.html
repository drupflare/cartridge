    Interface MemoryFS

    A MountFS backed by a Map, for an interpreter whose build exposes no filesystem.

    WHY THIS SHIPS RATHER THAN BEING A SNIPPET. It was hand-rolled nine times before it existed: four times in tests/recipes.spec.ts, twice in ADVANCED_USAGE.md, and once per library-style adapter in tests/interpreters/real-builds.spec.ts. Every copy was the same three no-op-or-store methods plus a TextDecoder in the writeFile branch, which is precisely the encoder this package promises no caller ever builds.

    It is NOT a MEMFS emulator and must not become one: the real emscripten MEMFS raises ENOENT for a write under a directory nobody created, and tests/mount.spec.ts keeps its own strict fake for exactly that reason. This one accepts any path, because an adapter that stores sources in a Map has no directories to get wrong.
